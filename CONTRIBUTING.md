# Contributing to the Agentic Governance Matrix

Thank you for contributing to the open-source standard for AI Production Readiness!

## How to Contribute

### 1. Regulatory Mappings
If you have expertise in a specific regulatory framework (SAMA, PDPL, CBUAE, GDPR, etc.), submit a Pull Request with:
- New YAML files in `/regulatory-mappings/`
- Mappings to the 3 RegOps pillars (Intent Verification, Dynamic Boundary Enforcement, Deterministic Proof)

### 2. Schema Enhancements
Propose improvements to the Deterministic Proof Artifact schema by:
- Opening an Issue with your use case
- Submitting a PR with backward-compatible changes to `/schemas/`

### 3. Documentation
Help improve this standard by:
- Adding implementation examples
- Clarifying ambiguous language
- Translating to other languages

## Code of Conduct
- Be respectful and inclusive
- Provide constructive feedback
- Cite sources and give credit

## Review Process
All contributions are reviewed by the ComplyFlow AI team and community maintainers. We aim to respond within 5 business days.
