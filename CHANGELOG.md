# Changelog

All notable changes to the Agentic Governance Matrix will be documented in this file.

## [1.0.0] - 2026-10-24

### Added
- Initial release of the Agentic Governance Matrix specification
- Core README with Manifesto and 3 Pillars of RegOps
- Deterministic Proof Artifact JSON schema (`/schemas/deterministic-proof-schema.json`)

Establishes the open-source standard for AI Production Readiness Architecture, specifically designed for GCC regulatory environments (SAMA, PDPL, NDMO).
