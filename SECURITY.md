# Security Policy

## Supported Versions
| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability
ComplyFlow AI takes the security of the Agentic Governance Matrix seriously. If you believe you have found a security vulnerability, please report it to us by emailing **fazal@complyflow.net**. 

Please do not open a public GitHub issue for security vulnerabilities.
